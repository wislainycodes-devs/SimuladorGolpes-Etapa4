# Simulador de Segurança Digital - Você Cairia Nessa?

Projeto desenvolvido para a Entrega 4 (Etapa I) da disciplina de Projeto Integrador III (PI-III) no curso de Engenharia de Software / IA na FAMA.

A ideia do projeto é bem simples e prática: criar uma ferramenta interativa para ajudar as pessoas a identificarem golpes e fraudes digitais do dia a dia antes de saírem clicando em qualquer link ou fazendo transferências.

---

### Como funciona?

Em vez de ser só um texto chato sobre segurança na internet, montamos uma simulação que imita a tela de um celular de verdade.

- O usuário passa por 6 situações reais de tentativas de golpes (mensagens suspeitas, pedidos urgentes no WhatsApp, links falsos, etc.).
- Para cada situação, dá para escolher qual atitude tomar.
- O simulador mostra na hora se a escolha foi segura ou não, além de destacar os sinais de alerta (red flags) diretamente na conversa.
- No final, tem um resumo com o placar de acertos e dicas essenciais de prevenção.
